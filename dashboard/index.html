Isolation

Each agent connects with its own role. Row-level security hides every other machine's rows.

ALTER TABLE traces ENABLE ROW LEVEL SECURITY; ALTER TABLE metrics ENABLE ROW LEVEL SECURITY; ALTER TABLE logs ENABLE ROW LEVEL SECURITY; GRANT SELECT ON traces, metrics, logs TO agents; -- agent_stockholm, agent_helsinki, agent_vantaa REVOKE ALL ON SCHEMA public FROM PUBLIC; -- as agent_helsinki SELECT count(*) FROM traces WHERE source = 'stockholm'; -- 0, always
